# Thu 12 Nov 2026

**The three that matter:** AWS released a free, offline emulator of more than 200
of its own services, with every line written and tested by agents. Google put a
decisions endpoint behind the Gemini API that scores options in a single forward
pass and bills no output tokens. An independent reanalysis of the Event Horizon
Telescope data says the 2019 black hole ring was real after all.

## Dev + infra

### AWS shipped a local emulator of itself, written by agents
Free, offline, and generated: over 400 Smithy API models covering more than 200
services. Fidelity tests are corrected against the real cloud first, so they record
how AWS actually behaves, then agents build the emulator until it passes. The point
is giving a coding agent an infrastructure loop it can run and check on its own
machine.
[source](https://www.allthingsdistributed.com/2026/11/aws-emulator-and-the-engineers-job-when-agents-write-the-code.html)

### Zellij 0.46 ships its own terminal emulator
`zellij terminal` runs the multiplexer as a native desktop app on Linux, macOS and
Windows, tuned for typing latency and scrollback rather than the usual benchmarks.
Nothing changes if you keep running it inside another terminal. The new attention
inbox and tray-icon session previews exist because people now leave coding agents
running in background panes.
[source](https://zellij.dev/news/terminal-inbox-session-previews/)

### Tim Peters, who gave Python timsort and its Zen, has died
Guido van Rossum's memorial credits him first with convincing Python to allow mixed
int/float arithmetic, then with the 2002 sort that Java and Android later adopted.
PEP 20 is the famous part. The durable part is the mailing-list habit of explaining
patiently why something could not work, which set the tone for early core
development.
[source](https://discuss.python.org/t/in-memoriam-tim-peters-1952-2026/110028)

## AI research + releases

### Google's new endpoint scores choices instead of generating them
`gemini-decision-1` evaluates candidate options in one forward pass: up to 1,000
yes/no, multiple-choice or rubric questions against a single multimodal input of
256K tokens, in 150–250ms end to end, at $0.10 per million input tokens with zero
output tokens billed. Every answer carries a 0–1 confidence, so ambiguous cases can
route to a fallback.
[source](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)

### A two-stage recipe distils a transformer into pure Mamba
Apple's argument is that initialisation is what was missing. Distil the transformer
into a linearised attention model using an adaptation of the kernel trick, then into
a Mamba with no attention blocks at all. At Pythia-1B scale the student reaches
14.01 perplexity against the teacher's 13.86. Tasks leaning on in-context recall
still show gaps, so hybrids are not dead.
[source](https://machinelearning.apple.com/research/attention-mamba-distillation)

## Hardware

### A voltage glitch turns a cheap mining card into a better-than-retail A100
Fault injection on the GA100 die lets an operator blow arbitrary fuses, which is
enough to convert a CMP 170HX into what reports as an 80GB A100. NVIDIA binned
retail parts to a yield-safe 108 SMs; the unlocked card runs 124 and measures 85.9
TFLOP/s FP16 against a retail A100's 72.5. NVLink and PCIe Gen4 come back too.
[source](https://blog.kate.land/posts/using-voltage-glitching-to-unlock-the-a100/)

## Homelab

### Podman 6.2.0 closes an auto-update hole worth patching this week
Image labels were copied straight into the container, so a malicious image could
name the auto-update unit and have Podman restart arbitrary systemd units as that
user — `poweroff.target` included. Two more land with it: a crafted image can match
any other image's digest, defeating digest and signature checks, and the default
seccomp socket deny rule could be bypassed.
[source](https://github.com/podman-container-tools/podman/releases/tag/v6.2.0)

## Science + space

### An independent algorithm reproduces the ring that critics called an artefact
A CSIRO-led team reimaged the Event Horizon Telescope data using a method with no
prescriptive shape priors, built on observables immune to calibration error — the
specific objection raised against the original reconstruction since 2022. The ring
comes back at 42.2 ± 1.5 microarcseconds, implying 6.5 ± 0.5 billion solar masses.
Open access in Nature.
[source](https://www.nature.com/articles/s41586-026-11241-9)
