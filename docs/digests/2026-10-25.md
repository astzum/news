# Sun 25 Oct 2026

**The three that matter:** A malformed Brotli stream can corrupt memory in anything
that decompresses attacker-supplied data, which is most HTTP clients. systemd has
merged the plumbing to write leaf programs in Rust. And Block trained a conversational
speech model with no text anywhere in the pipeline.

## Dev + infra

### A malformed Brotli stream writes past the decoder's eight-byte buffer
Node.js shipped the fix as HIGH in its October release: an invalid block switch is
reported as "need more input" rather than a permanent format error, so the streaming
decoder keeps appending bytes. Memory corruption, disclosure or RCE for anything
calling `node:zlib` on untrusted input. Fixed in 26.12.1, 24.22.1 and 22.23.4; upstream
brotli patched 1.0.10, 1.1.1 and 1.2.1 on 21 October.
[Node.js](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases)

### systemd will accept programs written in Rust from version 263
Merged 24 October — 19 commits, about 5,100 lines, by Christian Brauner. Leaf programs
only; the core library stays C. No Cargo (Meson builds it), C linkage is mandatory, and
no existing C gets ported. Toggled with `-Drust=`, auto by default. First user is
systemd-keyring-setup, not yet landed. Binaries come out 32KB against 20KB for the C
equivalent.
[systemd](https://github.com/systemd/systemd/pull/44324)

### Swapping a linear scan for a binary search cut one boot path from 268s to 50ms
Google's Tarun Sahu found `memblock_add_range()` and `memblock_isolate_range()` walking
their region arrays linearly. Under heavy fragmentation with Kernel Handover — many
thousands of disjoint folios — memory retrieval took around 268 seconds; with a binary
search, around 50 milliseconds. Ordinary boots will not notice. It is in the memblock
pull request for Linux 7.4.
[Phoronix](https://www.phoronix.com/news/Linux-7.4-memblock)

## AI research + releases

### Dessa learned to talk from audio alone, with no text anywhere in training
Block's research lab trained a full-duplex speech model from scratch on human
conversation — no text corpus, no pretrained base — on one GB200 NVL72. It listens and
speaks simultaneously, laughs mid-sentence and adjusts volume when asked, none of it
explicitly taught. Inference runs faster than real time on an M4 Max. No weights;
safety researchers get early access.
[Block](https://block.xyz/dessa)

## AI industry

### Dream Labs is selling robot control by the hour
Dream-1 takes head and wrist camera frames and returns 1.6 seconds of end-effector
poses per API call. Because it outputs gripper position rather than joint angles, it
drove 27 unseen simulated robots and four real ones zero-shot. $3/hour, or $2 for
flash, on a $90M seed. The comparison numbers come from Robocurve, not from the lab
itself.
[Dream Labs](https://dreamlabs.ai/research/dream-1/)

## Hardware

### An RTX 3090 Ti does 157 TFLOPS of BF16 once you unlock it
A Linux kernel module writes the GA10x speed selectors and performs a function-level
reset before NVIDIA's unmodified driver binds the card, lifting the artificial FP/BF16
issue-rate cap. Measured: 87.5 to 157.4 TFLOPS on a 3090 Ti, +25–80% on BF16 GEMM,
+14–36% on LLM prefill. Decode and INT8 barely move — bandwidth-bound. Costs a second
on resume.
[gpu-unlock](https://github.com/Zagitta/gpu-unlock)

## Homelab

### A 40B coding model with 2.5B active parameters and an Apache licence
Flint, from Recursive Superintelligence, is a 49-layer MoE — 256 experts, six routed
per token, 39.8B total — with a 262k context, aimed at coding agents. It claims 54.9%
on Terminal-Bench 2.1 and 74.2% on SWE-bench Verified. The number that matters here is
the active count: GGUF builds are already trending, so this plausibly runs on one
consumer GPU.
[Hugging Face](https://huggingface.co/RecursiveSI/flint)

## Science + space

### A single positron, trapped and read out one quantum state at a time
Gabrielse's group at Northwestern suspended one positron in a Penning trap and resolved
its cyclotron and spin states with microwaves, out in Physical Review Letters. The
point is a cleaner comparison of the positron's magnetic moment against the electron's,
which is a direct test of CPT symmetry. Phys.org puts the target precision gain near
30×; the paper claims no figure.
[arXiv](https://arxiv.org/abs/2605.08147)
