# Thu 08 Oct 2026

**The three that matter:** curl pulled its release forward to 14 October because one of
twenty-two pending CVEs is severity HIGH — only the third in five years. Chrome 155 ships
JPEG XL decoding through a pure-Rust decoder, reversing years of refusal. And NVIDIA's
128GB DGX Spark now costs $6,950, up from $3,999 at launch.

## Dev + infra

### curl cut its release cycle short for one bad bug
8.23.0 lands 14 October with CVE-2026-92392 fixed plus twenty-one lesser flaws. The project
has published only two HIGH-severity CVEs since 2021, the last being the 2023 heap overflow
CVE-2023-38545. No details until release morning; distros@openwall and paying support
customers get advance notice. Plan the patch window now rather than reading about it later.
[post](https://daniel.haxx.se/blog/2026/10/07/twenty-two-pending-curl-vulnerabilities/)

### Chrome 155 ships JPEG XL, and the decoder is Rust
Decode support only. Google credits the Interop Process, where JPEG XL was a popular
proposal in 2026 and several years before. The integration is jxl-rs, with unsafe code
confined to a vetted SIMD layer that needed Rust's `target_feature_11` stabilised first;
fuzzing has turned up no memory-safety bugs across its whole history. 30–50% better
compression than JPEG.
[post](https://developer.chrome.com/blog/jpeg-xl-in-chrome)

### Kubernetes 1.35 won't start a kubelet on a cgroup v1 node
`failCgroupV1` now defaults to true, so a lingering v1 node fails at kubelet startup rather
than degrading quietly. kubeadm's SystemVerification preflight has gone from warning to
error on init, join and upgrade. `failCgroupV1: false` is an explicit temporary escape
hatch. Memory QoS, still alpha in 1.36, only works on v2 at all.
[post](https://kubernetes.io/blog/2026/10/06/kubernetes-cgroups-v2-shift/)

## AI research + releases

### Claude Haiku 5.5 is 75% cheaper than Haiku 4.5
$0.10 per million input and $0.50 output below 100k tokens, five times that above — so the
cost model now depends sharply on prompt length. Adjustable effort settings, available on
AWS, Google Cloud and Azure immediately. 72.4% on OSWorld 2.1 offline, 57.4% on Humanity's
Last Exam with tools, 39.2% Terminal-Bench 4.0.
[announcement](https://www.anthropic.com/claude-haiku-5-5)

## AI industry

### OpenAI's Decisions API bills input only
Public beta, with GA promised "in the coming weeks". `POST /v1/decisions` takes text or
images and returns a probability, a choice with per-option probabilities, or a
rubric-weighted score — roughly 10x faster than Responses. $0.10 per million input tokens,
output free. `gpt-6-luna` is the only model, so this is a floor, not a lineup.
[docs](https://developers.openai.com/api/docs/guides/decisions)

## Homelab

### Strands Decider 2B answers in ~115ms on a 3090
Qwen3.5-2B with the LM head removed and a ~1M-parameter pointer head bolted on, torso
fine-tuned with a rank-16 LoRA. Weights, training data and every script are published, as
is the version history through v19. Median 115ms on an RTX 3090, 153ms on an M3 MacBook;
3rd of 33 in its size class on JevBench's public set.
[post](https://strandsagents.com/blog/introducing-strands-decider/)

## Hardware

### The 128GB DGX Spark is now $6,950, up from $3,999
A 64GB model arrives 23 October at $4,999 from Acer, ASUS, Dell, Gigabyte, HP and MSI,
keeping the ConnectX-7 200GbE networking. ServeTheHome bought GB10 nodes at roughly $3,000
each earlier this year; rebuilding that eight-node cluster today is a $50k-plus job. They
point at rising memory prices, and at AMD's 192GB Gorgon Halo boxes this month.
[post](https://www.servethehome.com/nvidia-dgx-spark-64gb-launched-and-big-128gb-gb10-price-increases/)

## Science + space

### Chemistry's Nobel goes to reactions that pick their own handedness
Henri Kagan and Kenso Soai share the 2026 prize for non-linear effects and autocatalysis in
asymmetric synthesis. Kagan's 1986 work got unexpectedly large excesses of one mirror image;
Soai's 2003 reaction produced only one, which nothing but life had managed. The physics
prize went to Francis Halzen alone, for IceCube and astrophysical neutrinos.
[press release](https://www.nobelprize.org/prizes/chemistry/2026/press-release/)
