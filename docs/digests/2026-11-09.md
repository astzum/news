# Mon 09 Nov 2026

**The three that matter:** A critical Linux checksum bug has been weaponised into
a working guest-to-host root escape from inside a Firecracker microVM, with the VM
left running and reachable over SSH. systemd has merged Rust support, but only for
standalone binaries — the shared core stays C until Rust fixes its stable-ABI
problem. A patched llama.cpp fork runs a 284B-parameter DeepSeek on a 64GB desktop
with no GPU at all.

## Dev + infra

### A Firecracker guest took over a root host process and the VM stayed up
pwn's Part 2 chains CVE-2026-99999 — a CVSS 9.3 IPv4 bug where `skb_checksum_help`
rewrites an already-validated header — into host code execution. From the guest
they walked EPT to find their own page, located the vCPU thread's saved `pt_regs`,
and redirected the return from `KVM_RUN`. The kernel fix landed in 7.3 and stable
backports; this is what the bug is actually worth.
[source](https://pwn.ai/blog/firecracker-escape) · [CVE](https://cveawg.mitre.org/api/cve/CVE-2026-99999)

### systemd takes Rust in leaf binaries only, and says why
Brauner and Poettering accepted Rust for individual binaries while ruling it out
of `libsystemd-shared.so`, because Rust still has no first-class shared-library
story and static linking across 180-plus small binaries would duplicate code
everywhere. The C core gets wrapped as crates instead, so helpers like the fd-based
`chase*()` path lookup stay the single implementation.
[source](https://amutable.com/blog/systemd-loves-rust)

## Homelab

### 284B DeepSeek runs on a 64GB desktop with zero GPUs
llama-modchip v2.4.0 quantises DeepSeek-V4-Flash (13.17B active) to 1.71 bpw —
56.56 GiB on disk, 57.61 GiB peak RSS at 256K context — for 44.4 tok/s prefill and
9.1–14.7 tok/s decode on 16-core Zen 5. The catch is real: its custom block-64
tensors are type ID 40, so stock llama.cpp, Ollama and LM Studio reject the files
outright.
[source](https://github.com/synchopate/llama-modchip)

### Nspawn 3.0 answers the Docker Engine API on the host
Point `DOCKER_HOST` at `/run/nspawn/api.sock` and `docker run`, `exec` and `cp`
drive systemd-nspawn machines instead of containers — enough for GitLab Runner's
docker executor. 2.0 only served a read-only API inside machines. The socket ships
disabled, and note the footgun: any user granted `org.nspawn.manage` is effectively
root on the host.
[source](https://blog.nspawn.org/posts/nspawn-3-0-a-docker-compatible-engine-api-for-systemd-nspawn-containers/)

## Science + space

### The cuprate pseudogap is electron pairing, not frozen order
Shot-noise spectroscopy through an STM tip shows the extra noise of paired charges
switching on exactly at the local pseudogap energy in BSCCO — up to 70 meV, varying
spot to spot — and fading under 6 tesla as pairing is suppressed. That rules out a
pure charge-density-wave origin and points the hunt for higher critical temperatures
at phase coherence instead of pairing strength.
[source](https://doi.org/10.1126/science.adt3444)
