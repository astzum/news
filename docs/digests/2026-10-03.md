# Sat 03 Oct 2026

**The three that matter:** llama.cpp can now serve decision models locally, including a
144M one that answers in 3ms. Rust 1.99.0 lets you write C-ABI variadic functions in
Rust itself. And GitHub is rate-limiting private vulnerability reports because automated
low-quality submissions are burying the real ones.

## Dev + infra

### Rust 1.99.0 lets you define C variadics, not just call them
Stabilised: `extern "C"` and `"C-unwind"` variadic functions via `core::ffi::VaList`, so
you can write the `printf`-shaped side of an FFI boundary in Rust. Also `Vec::into_parts`
and `from_parts`, `fs::set_times`, and `size_of_val_raw`/`align_of_val_raw` for unsized
raw pointers. `Box::leak` docs now warn against unleaking — it fights coming allocator work.
[release](https://blog.rust-lang.org/2026/10/01/Rust-1.99.0/)

### SvelteKit 3 is a tidy-up, and remote functions still aren't in it
Config moves from `svelte.config.js` into `vite.config.ts`, `$lib` becomes `#lib` using
standard subpath imports, and service workers lose boilerplate. `npx sv migrate sveltekit-3`
does most of the work. The headline feature people are waiting for — typed client-server
remote functions — is still blocked on Async Svelte behind an experimental flag.
[announcement](https://svelte.dev/blog/sveltekit-3-is-here)

### GitHub throttles vulnerability reports to dig maintainers out
Per-user daily caps now apply to new private vulnerability reports on public repos, with
custom limits and a trusted-reporter allowlist under Advanced Security settings. Comments
on existing advisories are unaffected. GitHub's reason is blunt: low-quality automated
reports are burying the ones that matter. No published number for the default cap.
[changelog](https://github.blog/changelog/2026-10-01-rate-limits-for-private-vulnerability-reports)

## Homelab

### llama.cpp now serves decision models over a `/v1/systemone` endpoint
Send a state plus typed questions, get a probability per option in one forward pass — no
parsing generated text. Five models supported, from Julia-1 at 144M (3ms) through OpenJev
at 27B (43ms, CC BY-NC). The API copies TypeSafe's System One format, so existing clients
just need a new base URL. Good fit for local routing and moderation.
[post](https://huggingface.co/blog/ggml-org/decision-models-in-llamacpp)

### Your local model probably isn't the reason your agent fails
Mingbird argues the harness is, and measures it: on an 18-task controlled benchmark across
four open models, it scores 0.886 against goose's 0.631, opencode's 0.479 and agent-mini's
0.405. The fixes are unglamorous — a byte-level prefill budget, a finish gate that re-reads
the task, loop detection. Authors flag the self-built benchmark and single-machine scoring.
[paper](https://arxiv.org/abs/2610.02001)

## AI research + releases

### Ai2 open-sourced the MoE training stack behind the next Olmo
Olmo-core 3 targets the cost that eats MoE's advantage: storing and routing experts across
a cluster. Their benchmark grew the expert pool from 8 to 128 while still picking four per
token — active parameters flat near 3.2B, total capacity 4.6B to 47B, throughput down under
5%. Benchmarked past a trillion total parameters.
[announcement](https://allenai.org/blog/olmocore3)
