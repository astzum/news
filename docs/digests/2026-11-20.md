# Fri 20 Nov 2026

**The three that matter:** A one-byte heap overflow in Ruby's string
case conversion gives unauthenticated code execution against Rails and Sinatra
apps in their default configuration. PostgreSQL 19 is out, and it can
defragment a bloated table without blocking reads or writes. Debian is deleting
legacy features from APT outright, on the grounds that AI-assisted security
research has made the complexity indefensible.

## Dev + infra

### One stray byte in Ruby's upcase gets you RCE on stock Rails
Most of Ruby's single-byte encodings have no capital ß, so upcasing one writes
two bytes where the loop only checked room for one. The output buffer is input
length plus 20, so 21 of them overflow it. Fixed in 3.3.14, 3.4.13 and 4.0.10;
GitLab 19.6.0 and GitHub Enterprise 3.22.5 still bundle affected builds. The
bug dates to 2.4.0.
[source](https://verialabs.com/ruby2shell/)

### PostgreSQL 19 can defragment a table without locking it
`REPACK (CONCURRENTLY)` reclaims bloat and reorders rows to match an index
while reads and writes continue; it replaces `VACUUM FULL` and `CLUSTER`, which
both took the table offline. Autovacuum also gets parallel index workers,
standbys get `WAIT FOR LSN` for read-your-writes, and creating the first
logical slot raises the WAL level without a restart.
[source](https://www.postgresql.org/about/news/postgresql-19-released-3449/)

### Debian is deleting APT features because AI keeps finding bugs in them
Julian Andres Klode is removing detached `Release.gpg` signatures, MD5/SHA1-only
repositories and repos with no Release file from unstable next week — cut-off 24
November. After the recent APT download-code flaw, he says, "the risk to users
from that complexity now significantly outweighs the benefits of retaining
backward compatibility." Pdiff and `Packages.xz` fallbacks are next.
[source](https://lists.debian.org/debian-devel-announce/2026/11/msg00001.html)

### PHP 8.6 brings partial application and a scalable poll API
`version_compare(?, '8.6', '>=')` now yields a Closure, readonly properties can
declare defaults, and the new `Io\Poll` wraps epoll and kqueue so ReactPHP and
AMPHP stop hitting `stream_select()`'s limits. It shipped alongside security
releases for 8.2 through 8.5, following Tuesday's critical pre-announcement —
patch those even if you are not upgrading yet.
[source](https://www.php.net/releases/8.6/en.php)

## AI research + releases

### Claude finished a black-hole calculation set up in 2003 and left undone
The question was whether the Hawking–Page phase transition stays abrupt where
spacetime no longer has a definite shape. Claude ran copies of itself as a
research group, derived almost every piece independently against known results,
and showed it does. A second result proves the exact floor of a bootstrap bound
physicists have been lowering since 2009. Two preprints; no applications.
[source](https://www.anthropic.com/research/claude-black-hole-physics)

## Homelab

### Valkey 9.2 does full replica syncs without forking
Forkless snapshots serve both disk and diskless full syncs from a
background-thread snapshot, which removes the memory spike that makes
fork-based replication painful on a small node. Zstd joins LZ4 for RDB and
replication, and `DELEX` deletes a key only if its value matches. The 9.1.4 and
9.0.8 point releases carry a use-after-free fix worth taking.
[source](https://github.com/valkey-io/valkey/releases/tag/9.2.0)

## Science + space

### Someone sent a message through a brick wall using gravity
The broadcaster moves a mass to encode bits; the receiver reads the resulting
change in the field with a gravimeter. The team got a message across roughly
0.7 metres of brick at one bit per minute. Gravity cannot be screened, which is
the whole point — the rate makes this a proof of principle, not a channel.
[source](https://doi.org/10.1126/sciadv.aee0802)
