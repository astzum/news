# Fri 13 Nov 2026

**The three that matter:** Jensen Huang has resigned as NVIDIA's CEO effective
immediately, with CFO Colette Kress stepping in on an interim basis. Anthropic
filed to go public and put a frontier lab's financials on the record for the first
time. Apache httpd and PostgreSQL both shipped emergency-grade fixes, including a
critical remote code execution bug in mod_http2.

## Dev + infra

### A critical RCE has been sitting in mod_http2 since 2.4.55
CVE-2026-119618 is a synchronisation bug in `assign_headers()` that corrupts the
heap and can reach code execution. 2.4.71 fixes it plus a mod_md null dereference.
Anthropic's OSS scanner reported it on 26 October; Google Cloud's vulnerability
research team found it independently a week later. Anything serving HTTP/2 on
2.4.55 through 2.4.70 is exposed.
[source](https://httpd.apache.org/security/vulnerabilities_24.html)

### PostgreSQL closed 52 CVEs at once, and buried version 14
Two are arbitrary code execution through type confusion — CVE-2026-6460 via
`ALTER ... SET DATA TYPE` and CVE-2026-18447 via output parameters, both CVSS 8.8 —
and dblink can append to arbitrary files. 18.7, 17.12, 16.16 and 15.20 carry the
fixes. 14.25 is the final PostgreSQL 14 release; that branch is now end of life.
[source](https://www.postgresql.org/about/news/postgresql-187-1712-1616-1520-1425-and-19-rc-2-released-3442/)

### Rust stabilised the never type after ten years and five failed attempts
`!` can now be named anywhere, and `Infallible` is an alias for it. The cost is a
breaking change: never-type fallback flips from `()` to `!` in the 2015, 2018 and
2021 editions, which will break rare code. Also stable in 1.100: the core
`Allocator` trait for `Vec` and `Box`, and Cargo unused-dependency reporting.
[source](https://blog.rust-lang.org/2026/11/12/Rust-1.100.0/)

## Homelab

### Six 32GB resizable BARs behind one PCIe switch, and the kernel bug in the way
Four Radeon AI PRO R9700s and two RTX 3090s sit behind a Broadcom PEX88096. ROCm
only enables peer-to-peer when each card's full 32GB is mapped, and the BIOS cannot
do it because every 32GB BAR consumes 64GB of address space — then Linux 7.0's
bridge window sizing gets it wrong too. The workaround is a published kernel module.
[source](https://doug.sh/posts/gpu-bars-behind-a-pcie-switch/)

## Science + space

### A white dwarf pulsing every eight minutes, paired with a Sun-like star
GPM J071507−114153 is the first long-period transient where the radio pulses can be
pinned to a white dwarf orbiting a G-type star rather than the usual red dwarf. Over
100 hours of MWA and MeerKAT data show the dwarf moving through its orbit, and
passing behind what looks like a stellar prominence. Published in Nature Astronomy.
[source](https://www.curtin.edu.au/news/media-release/researchers-discover-rare-star-system-that-emits-radio-signals-every-eight-minutes/)
