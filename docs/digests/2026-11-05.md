# Thu 05 Nov 2026

**The three that matter:** A critical APT bug let a remote attacker swap in their
own .deb using HTTP redirects and ordinary server errors, so patch every Debian and
Ubuntu box you own. C++26 failed its ISO final ballot — the first C++ draft ever to
do so — over Contracts. And AMD has guided to a quarter bigger than Intel's for the
first time.

## Dev + infra

### APT could be tricked into installing an attacker's package as root
CVE-2026-109518: a remote attacker combines redirects with routine transient HTTP
errors, APT retries the download, and the retry overwrites an existing hardlink with
a chosen payload — installed with root privileges. It needs `Acquire::Retries` set,
the default since APT 2.3.2. Fixed in bookworm 2.6.2, trixie 3.0.4, sid 3.3.6.
Reported by Max Justicz.
[APT security update](https://lists.debian.org/deity/2026/11/msg00005.html) ·
[tracker](https://security-tracker.debian.org/tracker/CVE-2026-109518)

### C++26 is the first C++ draft to fail its ISO ballot
The DIS vote closed 23 October without the required two-thirds majority. Andreas
Fertig, who votes on Germany's delegation, says the national bodies' comments point
squarely at Contracts: not ready to ship. Every path forward — revised DIS, back to
CD, publish as a Technical Specification, cancel — delays the standard. The only
precedent he could find, C++/CLI in 2006, was simply halted.
[Fertig](https://andreasfertig.com/blog/2026/11/cpp26-dis-failed-how-does-cpp-survive/)

### Go's JSON rewrite is done, and v1 now runs on top of it
`encoding/json/v2` and `encoding/json/jsontext` went stable in Go 1.27 back in
August; this is the Go team's proper write-up. Unmarshal is up to 10x faster, and
because v1 is implemented as v2 plus a set of compatibility options, you are already
running it. v2 defaults differ: duplicate keys, invalid UTF-8 and case-insensitive
field matching are now errors.
[Go blog](https://go.dev/blog/jsonv2)

## AI research + releases

### Anthropic has zkSNARK proofs of inference running at 110 tokens/second
FlashProve lets a provider commit to a model, then prove each response came from it
— the check you want if a router might be swapping in something cheaper. On Llama 4
Maverick (400B MoE, 4-bit) one H100 proves at ~110 tok/s, ~19MB per 1,024-token
request. That is 70–95x the GPU time of running it: a demo, not a product. Apache
2.0, Lean proofs.
[Anthropic](https://www.anthropic.com/research/provable-inference)

### Kimi K3.1 Pro is open weights at 2.8T parameters
Moonshot's MoE activates 104B of 2.8T, 1M-token context, natively multimodal,
shipped in 8-bit. It claims 65.7 on Terminal-Bench 4.0 against Claude Opus 5.5's
66.4 and 51.7 on SWE-Marathon, the best in its table — self-reported, with K3.1
evaluated under Claude Code. Weights are under Moonshot's own licence, not Apache.
vLLM and SGLang recipes are up.
[Hugging Face](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)

## Homelab

### The RTX Spark laptop runs local models four times slower on Linux
Plugged into wall power, the GPU pins at roughly 780MHz under Linux instead of
~2.2GHz, because the power table is encrypted and only Nvidia's Windows platform
controller can read it. MindStudio measured gpt-oss-120b at 13.9 tok/s on native
Linux versus 65.4 on Windows and 65.1 under WSL. Everything else works. Buy it for
WSL, not for Linux.
[MindStudio](https://www.mindstudio.ai/blog/linux-nvidia-rtx-spark-laptop)

## Science + space

### Two NASA spacecraft will burn their engines at closest approach this weekend
ESCAPADE's twins each fly a powered Earth flyby — gravity assist plus a nine-minute
trans-Mars injection burn at perigee, which NASA says no agency spacecraft has done
before. First burn around 5am EST Saturday 7 November, second 6am EST Monday 9
November, each adding about 1,000mph. Arrival is September 2027, then formation
flying to study Martian atmospheric loss.
[NASA](https://science.nasa.gov/blogs/escapade/2026/11/02/nasas-twin-escapade-spacecraft-to-slingshot-past-earth-on-way-to-mars/)
