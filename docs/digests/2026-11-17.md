# Tue 17 Nov 2026

**The three that matter:** The Rust compiler's parallel frontend is now on by
default for every nightly user. Hugging Face has handed its inference router
over to OpenRouter, so your HF token now reaches 80-odd providers. A malicious
page could drive uBlock Origin's element picker into injecting script on any
site.

## Dev + infra

### Rust's parallel frontend is on by default for nightly users
Since nightly-2026-11-14, type and borrow checking run on multiple threads
without an opt-in. With eight frontend threads the compiler team measured
`cargo check` on single crates at 44% less wall time, debug builds 36% less;
whole-graph `cargo check` on the cargo crate gained only ~15%. Nightly defaults
to two threads — raise it with `--jobs-frontend`.
[source](https://blog.rust-lang.org/2026/11/16/enabling-parallel-frontend-on-nightly/)

### Any website could make uBlock Origin inject script into any site
Smitty van Bodegom found the Firefox MV2 extension's element picker would accept
`postMessage` from an attacker's hidden iframe. A newline smuggled through the
request-type field turned a normal cosmetic rule into a trusted scriptlet
filter — one-click universal XSS. Fixed; the extension UUID leak that made it
targetable came from a stock filter rule. GPT-5.6 Sol found it; he verified it.
[source](https://iter.ca/post/ubo-uxss/)

### Tor shipped an emergency release while its relays are under flood
0.4.9.17 is a rapid response to an ongoing DDoS that has affected most relay
operators, with the important fix in IPv6-related relay DoS defences. The
project says relays are being overwhelmed by a flood of client circuits, it
does not have a complete answer yet, and more releases should be expected. If
you run a relay, upgrade.
[source](https://forum.torproject.org/t/security-release-0-4-9-17/22454)

## AI research + releases

### NVIDIA's new open model denoises text instead of predicting the next token
Nemotron-Labs-Sigma is a continuous diffusion language model: it refines
Gaussian noise in a 16-dimensional embedding space and commits whole blocks of
tokens at a time, reusing a normal KV cache for what's already settled. 3B and
8B, base and instruct, plain PyTorch, no custom kernels. Research artefact, not
an assistant.
[source](https://huggingface.co/nvidia/Nemotron-Labs-Sigma-8B)

### "Checked in Lean" is weaker than it sounds when an AI wrote the Lean
Of the 290 theorems in OpenAI's paper dump that came with Lean code, Kevin
Buzzard finds roughly 38 whose code does not even state the paper's main
result, let alone prove it. Code that compiles can still formalise the wrong
statement — his two-line counter-example mis-states Fermat's Last Theorem.
Compiling Anthropic's 13-million-line FLT proof took him 96 cores and 500GB.
[source](https://xenaproject.wordpress.com/2026/11/12/and-the-proof-is-checked-in-lean/)

## AI industry

### Hugging Face gave up its own router and plugged into OpenRouter
Inference Providers requests now go through OpenRouter, which picks a provider
per call on live price, speed and reliability and retries elsewhere on failure —
no code change, no markup, same token. Suffixes `:fastest`, `:cheapest` or a
provider name still pin it. HF says open-weight models went from 26.8% of
OpenRouter's tokens in October 2025 to 71.7% at the end of September 2026.
[source](https://huggingface.co/blog/openrouter)

## Hardware

### The $4,000 memory modules buy about 2% on EPYC Venice
Phoronix re-ran its EPYC 9686F 2P numbers with the MRDIMM-12800 kit clocked back
to 8800 MT/s. Across dozens of benchmarks the overall gap was roughly 2%. The
exceptions are the ones you'd guess: HPCG 26%, BRL-CAD 20%, WRF 11%, OpenFOAM
5–17%. MRDIMM-12800 isn't on sale anywhere yet; 8800 modules list at $3–4k per
64GB.
[source](https://www.phoronix.com/review/mrdimm-8800-12800-amd-epyc)

## Homelab

### Self-hosting the whole world's map tiles costs about $5 a month
PMTiles packs a tile pyramid into one file served over HTTP range requests, so a
storage bucket and a CDN that caches ranges is the entire stack. Bruce Röttgers
put the 139GB planet build on Bunny with 5x replication and priced a map session
at roughly 5MB — on his numbers, about 100x cheaper than Mapbox's $5 per 1,000
loads.
[source](https://bruceroettgers.eu/blog/protomaps/)
