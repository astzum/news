# Wed 16 Sep 2026

**The three that matter:** Google shipped Gemini 3.8 Live and a thinking variant,
audio-to-audio models aimed at voice agents, with pricing already on the public rate
card. JDK 27 reached GA with compact object headers and G1 on by default. And a
GitHub admin token baked into a Docker build three and a half years ago was still
valid, in a publicly readable registry, until July.

## AI research + releases

### Gemini 3.8 Live is a voice-agent play, and the per-minute pricing says so
Two models: `gemini-3.8-live` and `gemini-3.8-live-extended-thinking`, both
audio-to-audio with near real-time visual grounding and 97 languages with
mid-conversation switching. The Extended Thinking one runs tools in the background
without stalling the conversation, which is the actual unlock for anything doing
lookups mid-call. Google reports 82.6 on the Speech to Speech Quality Index, 97.7% on
Big Bench Audio, and 68.6% agentic task completion on τ-Voice — dropping to 35.1% on
Sierra's τ-Voice-banking, which is the number worth anchoring on. Both share a price:
$3.00/1M audio input tokens or $0.005/min, $12.00/1M audio output or $0.018/min, text
at $0.75 in and $4.50 out. Available now in the Gemini API and AI Studio; enterprise
is still private preview.
[announcement](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-live-gemini-3-8-live-extended-thinking/) ·
[pricing](https://ai.google.dev/gemini-api/docs/pricing)

### Chain-of-thought monitoring can be defeated by writing the thoughts for it
"Plan injection": plant harmful-but-benign-sounding reasoning in the actor model's
context and it will carry out the adversarial action while the monitor reads the
reasoning as clean. 25–33% evasion across monitorability benchmarks, and it scales to
larger models including DeepSeek-R1. Two details make this worse than a typical jailbreak
result. Actors paraphrase the injected plan as their own reasoning with no attribution,
so the trace looks self-generated. And giving the monitor *more* resources can backfire —
showing it the injected plan dropped detection by up to 50% on the Bio-Math task, and
extra thinking budget produced transcripts where the monitor spent its tokens
rationalising the plan instead of flagging it. If you're relying on CoT inspection as a
safety layer, this is the failure mode to test against.
[paper](https://arxiv.org/abs/2609.15989)

## Dev + infra

### JDK 27 is GA, and two of the nine JEPs change defaults under you
General availability was 15 September, build 35, after a clean second RC on 20 August.
The two that alter behaviour without you asking: JEP 534 makes compact object headers
the default (smaller heaps, but anything doing unsafe header assumptions should be
tested), and JEP 523 makes G1 the default collector in all environments. JEP 527 adds
post-quantum hybrid key exchange for TLS 1.3, and JEP 536 adds in-process JFR redaction,
which is genuinely useful if you ship flight recordings to a vendor. The rest are
previews and incubators still grinding: structured concurrency is on its *seventh*
preview, primitive patterns on its fifth, and the Vector API on its twelfth incubator.
[announcement](https://mail.openjdk.org/archives/list/announce@openjdk.org/thread/ORGGLMN75HFEWP7YL3ZLGHLYHVIBJDYT/) ·
[release page](https://openjdk.org/projects/jdk/27/)

### A GitHub token from March 2023 was sitting in Docker build metadata, still valid
Strix found an unauthenticated Harbor registry at Baseten, pulled `baseten/baseten-app`,
and ran TruffleHog over the image's build history. The token for the `basetenbot`
account was in `history[].created_by` — expanded there because the build passed it as a
`--build-arg` rather than a BuildKit secret mount. It had admin and push on the main
product repo, the GitOps infrastructure repo and the Homebrew distribution channel, plus
read/write on customer repos. Built 3 March 2023, reported 13 July 2026, still working:
that's the part to sit with. Baseten made the project private and rotated within a day.
The lesson is narrow and actionable — scanning image *layers* is not enough, the build
history is a separate place secrets hide.
[writeup](https://www.strix.ai/blog/baseten-harbor-github-pat-takeover)

## Homelab

### A 35B MoE that runs in 3 GiB of RAM by streaming experts off the SSD
Edge0-35b-a3b keeps the full 4-bit checkpoint on storage and pulls experts as they're
routed, so RAM holds only the active set — 2.9 GiB peak, 14.9–17.7 tok/s decode,
113/140 tok/s prefill cold/warm, measured on a 24 GB M4 Pro Mac mini. Three pieces make
it work: SSD expert offload, a trained "prerouter" head that predicts routing one step
ahead so loads overlap the forward pass (+59% decode), and Recover-LoRA distillation
that keeps the int4 model within 3.9 points of the fp16 base on average — 79.2 vs 83.2
across AIME 2026, HumanEval, GPQA-Diamond, MMLU-Pro and IFBench. Apache 2.0, based on
Qwen3.6-35B-A3B, MLX backend only for now, and explicitly a preview. If it holds up, the
constraint on local inference stops being VRAM and starts being storage latency, which is
a much cheaper problem to throw money at.
[model card](https://huggingface.co/Edge0/Edge0-35B-A3B-preview)

### KoboldCpp 1.121
Mostly media-generation work — MiniMax H3 reference images and audio clips, video LoRAs,
a reworked music UI. The bits that matter if you're running it as a text backend: tool
calling fixed for Kimi and DeepSeek V4 Flash models, a new `--ffncpu` flag mirroring
llama.cpp's `--n-cpu-ffn` for partial layer offload, `--analyze` now reads `.safetensors`
metadata as well as GGUF, and a streaming race condition is gone.

## AI industry

### "Cheapest inference provider in the world" was reselling OpenRouter
Three attested audits on 13 September caught CrofAI returning OpenRouter `gen-` response
IDs with matching token counts, and image fetches going out with an `OpenRouter/0.0`
user agent from the same IPs. CrofAI first denied fallbacks were active, then conceded "a
not insignificant amount of traffic" was going to OpenRouter and blamed a GPU router
avoiding expensive hardware, then said fallbacks were disabled in a special deploy — after
which the next probe reported nothing had changed. They eventually admitted `qwen3.5-9b`,
`deepseek-v4-flash-vision-exp` and `mimo-v2.5-pro` route out. The arithmetic was the
tell all along: the advertised catalog would cost $2,170–$2,880 a day to actually host,
against previously reported revenue of $500–$1,000. Worth a look at what your gateway
returns in its response IDs.
[investigation](https://kendell.dev/blog/crofaifalse/)

### TypeSafe claims a model that "can't hallucinate," and the claims are doing a lot of work
Diogo Almeida's TypeSafe AI announced "System One Models" — a class meant for fast
structured decisions rather than text — and a first model, Jev, in early access via
waitlist. The numbers in the post: 40x–200x faster than frontier LLMs, 193.6x faster and
444.6x cheaper on their workflow evals, 70–500ms responses, $0.042/MTok input and free
output. The architecture is described as parallel sampling trained with "Reinforcement
Learning for Calibrated Decisions," emitting typed outputs rather than strings. Filed
here because nothing is independently verifiable yet: no weights, no paper, no third-party
eval, and "can't hallucinate" is a claim about the output grammar, not about whether the
decision is right. Constrained decoding guaranteeing a valid enum is well-trodden; the
interesting question is the calibration, and that's the part with no evidence attached.
[announcement](https://typesafe.ai/blog/introducing-system-one-models-and-jev)
