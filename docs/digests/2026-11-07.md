# Sat 07 Nov 2026

**The three that matter:** Claude Code has been handing the signed-in account's
email address to arbitrary websites in the User-Agent header, and the fix that
shipped first does not work. A five-person lab trained a 65B dense model for $32M
that beats US open-weight models ten times its size at agentic coding. And GitHub
rebuilt Git storage for 7,200 pushes a second because agents, not people, are now
the ones writing.

## Dev + infra

### Claude Code put your email address in outgoing User-Agent headers
SEC EDGAR and Wikimedia ask callers for a contact address in the User-Agent, and the
model obliged with the account's own — issue #107757, opened 5 November, 670
thumbs-up by Friday. Anthropic shipped a `cc-plugin-privacy` mod in 2.1.317; users on
macOS and Windows 2.1.318 report it does not refuse the cases it documents. The real
fix, dropping the email from context, is promised next week.
[issue](https://github.com/anthropics/claude-code/issues/107757) ·
[HN thread](https://news.ycombinator.com/item?id=50385272)

### GitHub rebuilt Git storage for 7,200 pushes a second
"Rubicon" separates the part of a push that needs agreement — the reference update —
from the part that does not, since objects are immutable and content-addressed, so
writer nodes scale out. Internal tests held 5,000 concurrent agents on one repo. The
busiest repos today take dozens of writes a second; GitHub is planning for two orders
of magnitude more.
[GitHub](https://github.blog/engineering/architecture-optimization/inside-githubs-new-git-storage-architecture/)

## AI research + releases

### A 65B dense model trained for $32M tops US open-weight agentic coding
Ricursive's Ripple-65B Preview: 12T tokens, 1M context, Apache 2.0, and 80.52 on
TerminalBench 2.1 against 80.1 for Reflection Beam 501B and 76.4 for Meta's 816B Muse
Spark Open. Self-reported, and "US open-weight" is doing work in that claim. The $32M
is full R&D by a team that grew from one to five. An NVFP4 checkpoint fits a DGX Spark.
[Ricursive](https://www.ricursive.com/ripple) ·
[weights](https://huggingface.co/ricursiveAI/Ripple-65B-Preview)

### Gemini Omni 1.2 Flash drops video generation to $0.07 a second
Thirty percent under 1.1, now generally available. Clips go to 15 seconds from 10,
specified in one-second steps, and multi-turn editing means you fix one detail instead
of regenerating the whole thing — which is where the real cost saving is. Google says
fast sports action and complex physics are still weak.
[Google](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/)

## Hardware

### Nagare says it can stack SRAM-speed memory straight onto an accelerator
The Georgia Tech spinout's Z2RAM is two transistors and a shield, no capacitor,
deposited layer by layer on the die: no interposer, no bonding, 300mm DUV, no EUV.
Published cells hold data for over 300 seconds at 85°C, up from 100ms for a
conventional three-transistor design. The headline figures — 5x SRAM density, 14x DRAM
speed, 100+ layers — are projections.
[Tom's Hardware](https://www.tomshardware.com/tech-industry/semiconductors/gelsinger-backed-nagare-labs-capacitorless-z2ram-promises-sram-speed-with-dram-density-latest-published-cell-retains-data-for-over-300-seconds-at-85-c-but-further-figures-are-projected)

## Science + space

### Europe is getting a weather picture every 2.5 minutes
EUMETSAT published the first full-disc image from MTG-I2's Flexible Combined Imager,
taken 20 October, ten weeks after launch. The accompanying rapid-scan animation runs
45 hours from 3 November at 2.5-minute intervals — close enough to watch convection
build over the Mediterranean. Calibration is still underway; operational service is
not expected before Q2 2027.
[EUMETSAT](https://www.eumetsat.int/mtg-i2-first-images)

### A smartwatch detected hypertension about as well as an office cuff
Google's model reads photoplethysmography and accelerometry with no cuff calibration.
Over seven days against 24-hour ambulatory monitoring in 196 people: sensitivity
65.8%, specificity 90.0%, against 55.3% and 90.0% for initial office screening.
Beating office screening is a low bar, it still misses a third of cases, and this is
one small prospective study.
[Nature](https://www.nature.com/articles/s41586-026-11336-3)
