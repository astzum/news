# news

One page a day of AI, dev, and homelab news, researched and committed by a scheduled
Claude routine. Start at [`docs/index.md`](docs/index.md).

## How it works

A cloud routine runs each morning. Its entire instruction is "read `docs/GENERATOR.md`
in this repo and follow it" — so the prompt lives here, in version control, and
changing what the digest covers is a commit rather than a change to the routine's
config.

The routine researches the four beats, writes `docs/digests/YYYY-MM-DD.md`, and runs
two scripts that own the mechanical parts:

| | |
|---|---|
| `docs/record_seen.py` | appends the digest's URLs to `docs/seen.json` and prunes past 21 days, so stories don't repeat |
| `docs/build_index.py` | regenerates `docs/index.md` from digest frontmatter |

## Changing what it covers

Edit `docs/GENERATOR.md` and commit. The **Beats** section defines the four areas and,
more importantly, the bar each one has to clear. The **Verification** section is not
optional — search results in this topic are full of autogenerated pages that invent
model names, versions, and dates, so every item has to be confirmed against its
primary source or dropped.

## Making something reappear

Delete its URL from `docs/seen.json`.

## Pages

Not enabled yet. GitHub Pages on the free plan requires a public repo, and this one is
private, so for now the digests are read as markdown in the GitHub mobile app.

To turn the site on, make this repo public, then Settings → Pages → Source: deploy from
branch, `main` / `docs`. That is safe to do **only** because nothing private is meant to
land here: the digests are public-web links and commentary, and that is all this repo
should ever hold. The infra repo deliberately stays private and separate.
